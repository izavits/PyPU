# Citing PyPU

If you use PyPU in your research, please cite it:

```bibtex
@software{pypu,
  author  = {Zavitsanos, Ilias},
  title   = {{PyPU}: Positive-unlabeled learning in Python},
  url     = {https://github.com/izavits/PyPU},
  license = {BSD-3-Clause},
}
```

The same metadata is in
[CITATION.cff](https://github.com/izavits/PyPU/blob/main/CITATION.cff), which GitHub's
"Cite this repository" button uses.

Please also cite the papers of the methods you use. Each model's page in the
[API reference](api/index.rst) lists them under References.
